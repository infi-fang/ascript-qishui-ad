# opt project

> 一个"小白也能用"的手机自动化小工具 —— 让手机自己完成重复的领奖励操作。

---

## 这是什么

**opt project** 是一个跑在 iPhone 上的自动化小助手。它会帮你：

1. 打开 App
2. 顺手关掉挡路的会员弹窗
3. 找到入口点进广告
4. 等广告播完
5. 自动点领取，拿时长

然后自动进入下一轮，一直循环，直到当天领满。

你**不需要懂代码**：手机上装好 App、打开"设备服务"，电脑上跑一条命令，剩下的它自己来。

---

## 为什么做这一版：从"要懂技术"到"小白也能用"

这是本项目最重要的改进。

### 之前的版本（劝退小白）

早期版本更像一个"给开发者用的脚本"，对使用者有隐性门槛：

- 满屏 `OCR`、`paddleocr`、`Selector`、正则、坐标系……看日志像看天书，出问题完全不知道哪里错了
- 需要自己理解识别引擎、区域坐标、模板图匹配这些概念
- 换个手机、界面一变，不知道该改哪里
- 文档里全是技术术语，小白看完还是不敢动手
- 还得手动点进第一个广告，脚本才开始工作

**结果**：懂技术的人能用，普通人看着就放弃。

### 现在这一版（opt project）

我们把"技术复杂度"全部藏到了背后，把"人话"放到了前面：

| 对比项 | 之前 | 现在 |
|---|---|---|
| 日志提示 | `[扫描#3 paddleocr 命中] 置信度=0.98 (898,252)` | `找到"免"字了（把握 98%）→ 点进去` |
| 步骤说明 | `阶段三：监测入口（paddleocr 精准识别）` | `第 3 步：找进广告的入口` |
| 出错提示 | `FindImages 匹配异常: ...` | `参考图没匹配上，改用看文字的方式找` |
| 上手操作 | 要手动进第一个广告 | 第 1 轮脚本自己进，之后全自动 |
| 配置理解 | 要懂引擎/坐标/正则 | 只需改一个手机 IP，其余默认就能跑 |

**代码逻辑一行没动**——所有改动都是文案层面的（注释、日志、提示语、品牌名）。功能更稳，门槛更低。

---

## 这版对"做视频号内容"的好处

这个"小白化"改造，不只是让工具更好用，**它本身就是很好的视频号选题素材**：

1. **天然的故事线**："一个只有程序员能用的脚本，我把它改成了小白也能用的工具" —— 这种"技术平民化"的转变，是短视频最容易讲清楚、也最有共鸣的叙事。
2. **前后对比有画面感**：改造前的满屏英文报错 vs 改造后的人话日志，直接做成前后对比镜头，观众一眼就懂"变简单了"，不需要任何技术背景。
3. **受众面被放大**：技术教程受众窄，但"小白友好工具"人人都能看懂、都有代入感。潜在观众从"程序员"扩展到"所有想省事的人"。
4. **可讲的钩子多**：
   - "不用懂代码，一条命令搞定"
   - "以前看日志像看天书，现在它用大白话告诉你干了啥"
   - "我自己都看不懂以前写的东西，于是全改成了人话"
5. **信任感更强**：展示"我把技术细节藏起来、只留最简单操作"的过程，比直接炫技更能建立"这人是真为用户着想"的印象。

> 一句话：把这层"小白化"讲出来，视频就从"技术教程"升级成了"帮普通人解决问题"的内容，传播力完全不同。

## 开始之前：先装这几个软件（照着装就行）

> 分两边：**电脑（Windows）装 2 样，手机（iPhone）装 4 样**。全部装好后再往下看「快速开始」。
> 下面全是**官网链接**，别从网盘、论坛或不明下载站拿安装包——仿冒站很多。

### 一、电脑端（Windows）

| # | 要装什么 | 干嘛用的 | 官网 | 怎么装 |
|---|---|---|---|---|
| 1 | **Python 3.10 或更高** | 运行控制命令的环境 | [python.org/downloads](https://www.python.org/downloads/) | 下载 Windows 安装包双击安装，**务必勾选「Add Python to PATH」** |
| 2 | **ascript-mcp**（含 psutil） | 让电脑能连上并操控你的手机 | [PyPI 包页](https://pypi.org/project/ascript-mcp/) · [官方使用文档](https://www.ascript.cn/mcp) · [psutil](https://pypi.org/project/psutil/) | 装好 Python 后打开命令提示符，执行：`pip install ascript-mcp psutil` |

### 二、手机端（iPhone）

| # | 要装什么 | 干嘛用的 | 官网 | 怎么装 |
|---|---|---|---|---|
| 1 | **汽水音乐** | 要自动领时长的目标 App | [qishui.com](https://www.qishui.com/) | 官网点 iOS 下载，或 App Store 搜「汽水音乐」 |
| 2 | **AScript App** | 脚本在手机上运行的"容器" | [ascript.cn](https://www.ascript.cn/) | 在官网按 iOS 安装指引装好 |
| 3 | **AScript-WDA** | 让电脑能操控手机的桥梁 | [ascript.cn](https://www.ascript.cn/) | 随 AScript 一起装，装完在 AScript 里激活 |
| 4 | **iOS 激活工具**（ascript-ios-active.exe） | 把 WDA 激活成"已激活"状态 | [ascript.cn](https://www.ascript.cn/)（安装包来自官方 OSS `airscript.oss-cn-hangzhou.aliyuncs.com`） | 下载后**右键 → 以管理员身份运行** |

### 三、装完先检查这 4 件事

1. 手机 AScript 显示 **「已激活」**（没激活就用上面的激活工具，管理员运行）。
2. AScript「开发者」页里 **设备服务已打开**，显示形如 `192.168.x.x:9096` 的地址。
3. 手机和电脑连 **同一个 WiFi**。
4. 手机 AScript 保持 **前台、不锁屏**。

> ⚠️ 小白最常卡住的三处：
> - 激活工具弹出「Windows 已保护你的电脑 / 不够信任」→ 这是官方工具没有大厂签名导致的，点 **更多信息 → 仍要运行** 即可（详见排障手册第 1 节）。
> - 电脑提示 `python` 不是内部或外部命令 → 装 Python 时没勾 **Add Python to PATH**，重装并勾上。
> - 搜到一堆"汽水音乐下载站" → 只认上表的官网 `qishui.com`，其他域名多为仿冒。

## 快速开始

**前置条件**：Windows 电脑 + 装了 AScript 的 iPhone（已激活、开启"设备服务"、和电脑在同一 WiFi）。

```bash
# 1. 把 device_config.json 里的 host 改成你手机的 IP
#    （手机 AScript「开发者」页能看到，形如 192.168.x.x）

# 2. 检查设备连没连上
python scripts/device.py doctor

# 3. 一键部署 + 运行 + 看日志
python scripts/device.py all --key
```

想停下来：`python scripts/device.py stop`

## 目录结构

```
ascript-qishui-ad/
├── SKILL.md                  # Skill 定义：什么时候触发、怎么操作
├── device_config.json        # 设备地址（host 要改成自己手机 IP）
├── scripts/device.py         # 设备操作命令行工具
├── references/
│   └── troubleshooting.md    # 排障手册（激活/DNS/隧道/端口等全收录）
├── assets/project/           # 部署到手机的脚本（小白化后的版本）
├── dev-project/              # 原始代码仓库存档（保留技术版作对照）
└── releases/                 # zip 发布产物（不入库 git）
```

---

## 关于上传 Git

- ✅ **传本仓库源码目录**：可 diff、可回溯、clone 即用。
- ❌ **不传 zip**：二进制黑盒，git 无法追踪版本，且仓库本身会压缩，传 zip 是冗余。zip 只在发给不用 git 的朋友时才用。

`.gitignore` 已配置好，`releases/`、`*.zip`、`__pycache__`、`*.log` 等都不会被提交。
